# REDLINE — Image Archive

A responsive, fan-made image gallery based on the Redline visual references. Built with plain HTML, CSS, and JavaScript—no build step or dependencies required.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. The SVG artwork is in `assets/` and downloadable directly from the gallery.

## Features

- Responsive, logo-forward crimson and pink design
- Search and category filters
- Image detail dialog with description and file information
- Direct downloads of the SVG artwork
- Keyboard-accessible gallery cards and reduced-motion support

The included illustrations are SVG interpretations of the supplied visual references, not the original uploaded image files. This is an unofficial fan project.
