# REDLINE — Yandere Image Archive

A responsive, fan-made image gallery inspired by the dark-romance atmosphere of *Redline Yandere*. Built with plain HTML, CSS, and JavaScript—no build step or dependencies required.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. The four original concept illustrations are SVGs in `assets/` and are downloadable directly from the gallery.

## Features

- Responsive, dark editorial design with crimson accents
- Search and category filters
- Image detail dialog with description and file information
- Direct downloads of the original SVG artwork
- Keyboard-accessible gallery cards and reduced-motion support

The artwork is original concept imagery, not official game assets. This is an unofficial fan project; downloads are intended for personal use.
